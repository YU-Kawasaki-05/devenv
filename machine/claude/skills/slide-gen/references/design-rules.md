# Design Rules

## 基本方針
Notion / Linear / Stripe / Apple Keynote 系のスタイル。
余白広め・色数少なめ・情報設計優先。

## テーマ（theme.ts より）

```
背景:     #F7F7F3（薄いオフホワイト）
表面:     #FFFFFF
見出し:   #111827
本文:     #1E1E1E
補足:     #6B7280
線:       #E5E7EB
アクセント: #2563EB
強調背景:  #DBEAFE
フォント:  Yu Gothic（日本語環境）
```

## やってはいけないこと（アンチパターン）

```
× グラデーション背景をメインスライドに使う
× アイコンを過剰に使う（1スライド3個以上）
× 複数の強調色を使う
× テキストを詰め込む（行間なし・余白なし）
× タイトルを2行以上にする（サブタイトルに逃がす）
× 表を6行超で1枚に収める
× 座標をAIに自由指定させる
× AIっぽい装飾（虹色・過剰な囲み）
```

## やるべきこと

```
○ 1スライド1メッセージ
○ 余白を広く取る（pageX: 0.65インチ）
○ 強調色は1色（accent: #2563EB）のみ
○ 表・グラフには必ずキャプションをつける
○ 数式はmath layoutを使う（テキストboxに直書きしない）
○ 長い表は分割またはAppendixへ
○ 箇条書きは体言止めで統一
```

## フォントについて

WSL上でNode.jsが生成したPPTXをWindowsで開く場合、フォント名はWindowsのもので指定する。

```
日本語: "Yu Gothic"（游ゴシック）
英数字: "Yu Gothic" または "Aptos"（Office 2021以降）
等幅:   "MS Gothic" または "Consolas"
```

## AIっぽくない資料にするための観点

```
1. テキストが少ない（1スライドに多くて100文字）
2. 図・表・グラフで「見せる」
3. 余白が広い
4. 色が統一されている
5. フォントサイズの階層が明確（タイトル>見出し>本文）
```
