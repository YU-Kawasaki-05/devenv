# Privacy Policy

Do not put sensitive information in Google Calendar unless the user explicitly asks and the value is operationally necessary.

## Never Store in Calendar

- Test center ID
- Registration number
- Order number / invoice number
- Full application passwords
- Government ID details
- Full ES answers
- Detailed personal profile data
- User phone numbers
- Full home address
- Medical details
- Financial account details
- Private academic grades unless needed
- Confidential client details

## Usually Safe

- Company name
- Application type
- Public office or test center venue name
- Public venue address when needed for travel
- University course names
- Work meeting titles at a non-confidential level
- Public office or campus buildings
- Deadline date/time
- Test duration
- Required equipment
- Non-sensitive MyPage action labels such as `エントリーシート`, `WEBテスト`

## URLs

- Public recruiting URLs are safe.
- MyPage URLs should be omitted by default. Add them only if the user explicitly wants direct links and the URL does not expose tokens.
- Do not store one-time test launch URLs.
- Do not store URLs with session IDs, auth tokens, or one-time access links.

## Local Files

Local files may contain more detail than Calendar, but still avoid storing passwords, test center IDs, registration numbers, and private tokens.

For job-hunt local files, event IDs are usually safe and useful. For non-job-hunt local files, record event IDs only when a durable local note exists.
