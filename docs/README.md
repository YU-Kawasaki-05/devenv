# エージェント駆動開発環境・ハーネス利用マニュアル

このディレクトリは、AI エージェント (Claude Code / Codex / GitHub Copilot) を使った開発環境の **使い方ガイド** をまとめた場所です。

## 読む順番

エンジニア初心者でも順に読めば理解できるように構成しています。

| # | ファイル | 何が分かるか | 想定読了時間 |
|---|---|---|---|
| 1 | [`01_はじめに.md`](01_はじめに.md) | このディレクトリ・仕組みは何か。なぜ作ったか | 5 分 |
| 2 | [`02_用語集.md`](02_用語集.md) | 専門用語の意味 (Skill / Hook / Profile / Sync など) | 10 分 |
| 3 | [`03_セットアップ.md`](03_セットアップ.md) | 新メンバーが PC で開発を始められるようにする | 30 分 |
| 4 | [`04_日々の使い方.md`](04_日々の使い方.md) | 「これがしたい」→「こうする」のレシピ集 | 必要な時だけ参照 |
| 5 | [`05_トラブルシューティング.md`](05_トラブルシューティング.md) | エラーが出たときの対処 | 必要な時だけ参照 |
| 99 | [`99_整備作業報告書_2026-05-09.md`](99_整備作業報告書_2026-05-09.md) | 2026-05-09 に整備した内容のサマリ (経緯確認用) | 10 分 |

## 迷ったら

1. まず `01_はじめに.md` を読む
2. 用語が分からなくなったら `02_用語集.md` で都度確認
3. 「自分の PC で動かしたい」となったら `03_セットアップ.md`
4. 普段の作業中に困ったら `04_日々の使い方.md` か `05_トラブルシューティング.md`

## 更新ルール

- 仕様や運用が変わったらこのディレクトリも更新する
- 「やり方が変わった」「新しい Skill が増えた」「新メンバーが詰まった所」は積極的に追記
- `99_整備作業報告書_*.md` は変更しない (歴史記録)
