## 確立したエンジニアリング原則 (今後の運用にも適用)

| 原則 | 意味 | 今回の適用例 |
|---|---|---|
| Single Source of Truth | 真実源は 1 ヶ所 | `templates/<profile>/` |
| 一方向 sync | データ流の方向を固定する | 正本 → プロジェクト |
| dry-run ファースト | 不可逆操作の前に必ず予行演習 | sync.sh `--dry-run` |
| 沈黙より表明 | やらない理由も明記 | manifest の `pending` / `out of scope` コメント |
| 既存の慣習を尊重 | 仲間外れを作らない | slide-gen の symlink 化 |
| YAGNI | 今要らない機能は作らない | Copilot 用 project 配置は将来必要時に対応 |
| 整理と修復は別タスク | 性質の違うものを混ぜない | univ/.codex 修復は単独タスクで対応 |
